Classical Ciphers

The concepts behind CipherLab's encryption engine.

01

Caesar Cipher

Each alphabetic character is shifted by a fixed integer. For encryption, C = (P + K) mod 26. It is simple and useful for learning substitution and brute-force cryptanalysis.

E(P) = (P + K) mod 26
02

Vigenère Cipher

A repeating keyword supplies a different shift for each letter. This makes it stronger than a single Caesar shift while remaining a classical polyalphabetic cipher.

Cᵢ = (Pᵢ + Kᵢ) mod 26
03

Brute Force

Caesar has only 26 possible keys, so an attacker can test every shift. Real security requires modern cryptography and proper key management.
